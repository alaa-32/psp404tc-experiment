# Chinese claims — approval pending

The draft preserves deliberately inaccurate statements. No answer key is included.

CS1

In a survey about smartphone use in freezing weather, around 58% of participants used their phones to listen to music or podcasts, while around 28% used them to play games.

在一项关于严寒天气下智能手机使用情况的调查中，约58%的参与者使用手机听音乐或播客，约28%的参与者使用手机玩游戏。

CS2

In the same survey, more participants experienced apps crashing than problems with the phone’s operating system crashing.

在同一项调查中，遇到应用程序崩溃的参与者比遇到手机操作系统崩溃的参与者更多。

RB1

In a robot delivery experiment, every participant tried both delivery methods: receiving the object directly and picking it up from a table.

在一项机器人物品递送实验中，每位参与者都体验了两种递送方式：直接接过物品，以及从桌上拿取物品。

RB2

Participants gave the robot a higher average confidence score when it handed them an object directly than when it left the object on a table.

与机器人把物品放在桌上相比，当机器人直接把物品递给参与者时，参与者给机器人的平均信心评分更高。

EC1

In a restaurant donation experiment, researchers tested suggested donations of 50 cents, $1 and $3, along with a condition where no amount was suggested.

在一项餐厅捐款实验中，研究人员测试了建议捐款金额分别为50美分、1美元和3美元的条件，以及不建议捐款金额的条件。

EC2

In the same experiment, suggesting a donation of 50 cents produced a higher average daily donation total than suggesting $2.

在同一项实验中，建议捐款50美分时的平均每日捐款总额高于建议捐款2美元时的平均每日捐款总额。

ED1

In an online learning experiment, students using the version with game features achieved an average performance score of 0.80, compared with 0.49 for students using the version without game features.

在一项在线学习实验中，使用包含游戏元素版本的学生的平均表现得分为0.80，而使用不包含游戏元素版本的学生的平均表现得分为0.49。

ED2

In the same experiment, 38 students used the learning platform with game features, while 33 students used the version without them.

在同一项实验中，38名学生使用了包含游戏元素的学习平台，而33名学生使用了不包含游戏元素的学习平台。
