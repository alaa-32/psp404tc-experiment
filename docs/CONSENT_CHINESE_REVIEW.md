# 参与者信息与知情同意

**研究题目：** 从引用到决策：更便捷地获取证据是否影响人们对人工智能生成陈述的接受？

**大学：** 西交利物浦大学（XJTLU）

### 关于本研究

本研究调查大学生如何对照已发表的研究文献，核查人工智能生成的研究陈述。

### 我需要做什么？

您将阅读基于四篇已发表研究论文的八条人工智能生成陈述。

对于每条陈述，您将打开研究文献、查看证据，并决定是否在研究摘要中按原文采用该陈述。

本研究约需 **10–15分钟**。无需专业知识。

### 隐私与数据收集

我们将记录：

- 您对每条陈述作出的决定。
- 您完成每道问题所需的时间。
- 您与研究文献的交互，例如打开文档。

您的回答将通过随机生成的研究编号关联。我们不会询问您的姓名、学号、国籍或设备类型。

当您完成研究后，您的回答将通过 **FormSubmit.app** 传输至研究团队指定的数据收集账户。该服务也可能处理为传送和保护提交内容所需的技术信息。

研究回答的访问权限将限于获授权的研究团队成员，以及适用情况下的相关大学工作人员。结果可能以汇总形式呈现在学术报告和演示中。

研究数据将自提交之日起保存 **30天**，之后由研究团队从数据收集账户、通知邮件、导出文件和研究备份中删除。您的浏览器中也会保存一份副本。您可以使用研究中的控件删除该副本；过期的本地进度会在您下次打开研究时删除。删除浏览器副本不会删除已提交的回答。如果您之后可能申请删除数据，请保留您的研究编号。

### 自愿参与

您完全自愿参与本研究。您可以拒绝参与或随时停止参与，且不会受到任何处罚。

如果您在完成研究前退出，您未完成的回答不会在线提交。您可以使用研究中的退出控件，从设备上删除任何本地保存的进度。

提交回答后，您可以在30天的数据保留期内发送邮件至 Alaa.Mezghiche26@student.xjtlu.edu.cn，申请删除您的回答。请在邮件中提供研究结束时显示的研究编号，以便研究团队查找并删除您的回答。

### 问题或疑虑

如果您对研究或您的数据有任何疑问，请联系：
